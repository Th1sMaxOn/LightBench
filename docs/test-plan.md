# Перевірки LightBench

| ID | Вхід | Критерій |
|---|---|---|
| LB-T01 | Дві чисті Docker-збірки й запуск | Однакові ELF/HEX/BIN, банер, окремі ADC/IMU/button стани |
| LB-T02 | Періодичні незалежні потоки | Час завершення кожного, інтервал >40 мс враховано як gap |
| LB-T03 | ADC 0, 2048, 4095; зміна lux моделі | Raw у діапазоні, напрям AO перевірений окремим запуском |
| LB-T04 | Вектори 0°, 90°, 180°, нуль та 0.849/1.151 g | Числовий кут лише за 0.85..1.15 g включно |
| LB-T05 | run/stop/run та повторні команди | Номер серії зростає, статистики скидаються, точки залишаються |
| LB-T06 | Брязкіт, утримання, повторне натискання | Після 30 мс стабільності одна точка; поза серією not_running |
| LB-T07 | Вік 40/41 мс, skew 20/21 мс, wrap uptime | Межі включні; непридатна пара має reason flags |
| LB-T08 | Відомі вибірки, порожня серія, відсутність кутів | Окремі знаменники; empty/invalid замість вигаданого нуля |
| LB-T09 | 70 позначок | Останні 64, overwritten=6, правильний порядок |
| LB-T10 | Export та нові записи | Стабільний знімок, count і CRC32 канонічних байтів |
| LB-T11 | NACK/timeout/ID; IMU recovery; ADC failure | ADC триває при IMU fault; ADC fault зупиняє серію |
| LB-T13 | Команди, довгий рядок, RX overflow | Помилка й відновлення на наступному рядку; status ціль ≤100 мс |

Host-тести перевіряють App, драйвер і Platform з підставними портами. Автоматична перевірка залежностей забороняє HAL у App/Devices. Ціль покриття App+Devices: щонайменше 90% рядків і 80% гілок; не стосується vendor/HAL та не доводить правильність схеми.

Wokwi запускається з цією схемою та власним ELF. I²C ID, burst, NACK і UART декодуються sigrok/PulseView. ADC оцінюється за raw і PA4, кнопка за PA1 і маркером PB0. Порівняння цифрових байтів з UART обов'язкове: успішна збірка не доводить симуляцію.

LB-T12 належить ЛР3: внутрішня flash, CRC, commit marker, reset, перерваний запис. У ЛР2 журнал RAM втрачається після reset. S1–S3, година роботи, профілювання таймером і baseline FreeRTOS також залишаються ЛР3.
