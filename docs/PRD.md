# LightBench

Пашко Максим Ігорович, ІО-32.

## Призначення

Оператор порівнює рівень світла та положення носія у вибраних контрольних точках. LDR дає raw, MPU6050 дає вектор прискорення, кнопка позначає пару з відомим часом. UART дозволяє почати серію, отримати статистики й експортувати точки. У Wokwi світло й нахил незалежні; симуляція не доводить фізичного причинного зв'язку між ними.

Середовище: Ubuntu 24.04, Docker, STM32 HAL, Wokwi. Платформа Nucleo-C031C6. ЛР1 охоплює середовище, UART/LED, вимоги й компоненти. ЛР2 реалізує одночасний збір, точки, статистики, RAM-журнал і експорт. Постійне збереження FR-12 залишається ЛР3. Для ЛР4 передбачено FreeRTOS, її методички немає. ЛР5–6 невідомі.

## Правила даних

Світло зберігається як raw 0..4095 без перетворення на люкси. Нахил θ=acos(az/|a|), 0..180°, придатний лише за 0.85≤|a|≤1.15 g. Нульовий вектор і помилка шини дають invalid. Формат кута: соті градуса; sentinel 65535 і прапорець для invalid.

Кожний канал має власний час завершення. Пара придатна при віці кожного ≤40 мс, розриві між джерелами ≤20 мс та придатному куті. Час точки відповідає підтвердженню кнопки після debounce. Час uint32 мс є uptime, не календар. Різниці коректні через одне переповнення за інтервалів <2³¹ мс. Серія обмежена годиною, щоб мати визначені межі сум і лічильників. Статистики raw й кута мають окремі знаменники.

## Функціональні вимоги

| ID | Система повинна | Обсяг / тест |
|---|---|---|
| FR-01 | Збирати HAL-прошивку в Docker; друкувати версію й окремі стани ADC, IMU, кнопки через UART 115200 8N1. | ЛР1/2, T01 |
| FR-02 | Збирати два незалежні потоки по 20 мс із часом завершення, gaps для інтервалів >40 мс і окремими failures. | ЛР2, T02 |
| FR-03 | Передавати raw без тверджень про точні люкси або присутність людини. | ЛР2, T03 |
| FR-04 | Обчислювати θ та його придатність за правилами вище. | ЛР2, T04 |
| FR-05 | run за справного ADC починає нову серію, скидає статистики, збільшує ID; stop завершує один раз. Попередні точки зберігаються. Повторний run відхиляється. | ЛР2, T05 |
| FR-06 | Після стабільного натискання 30 мс створювати одну точку протягом наступних 50 мс. Утримання не повторює запис; поза серією not_running. | ЛР2, T06 |
| FR-07 | Зберігати ID, час точки й обох джерел, raw, θ, причини непридатності. Відхилена пара також зберігається для аналізу якості. | ЛР2, T07 |
| FR-08 | Після stop давати ADC/pose counts, failures/gaps, mean/min/max raw, число придатних кутів і mean; порожня серія empty, без кутів mean_angle=invalid. | ЛР2, T08 |
| FR-09 | Тримати 64 останні точки в RAM; перезапис найстарішої збільшує overwritten. | ЛР2, T09 |
| FR-10 | export формує сталий знімок, CSV, count і CRC32 канонічних байтів. Збір та кнопка працюють під час експорту; повторний export має busy. | ЛР2, T10 |
| FR-11 | NACK/timeout IMU не зупиняє ADC; повтор ініціалізації не частіше 1 с. Помилка ADC завершує серію, наступні проби ADC тривають. | ЛР2, T11 |
| FR-12 | Відновлювати підтверджені записи з внутрішньої flash після reset; відкидати обірвані/пошкоджені записи за CRC і повідомляти втрату. | ЛР3, T12, НЕ реалізовано |
| FR-13 | Обробляти run, stop, status, export, selftest, imuaddr 0x68/0x69; відхиляти невідомі й довгі рядки. Ціль короткого status ≤100 мс за відсутності черги TX. | ЛР2, T13 |
| FR-14 | LED світиться під час серії; UART розділяє ADC/IMU faults, RX/TX overflow. Сховище позначається ram_volatile. | ЛР2, T11/T13 |

T01..T13 означають LB-T01..LB-T13 у [плані перевірок](test-plan.md). Виміряні значення та обмеження наведені у [validation](validation.md).

## Компоненти та альтернативи

| Компонент | Інтерфейс і функція | Відхилена альтернатива |
|---|---|---|
| LDR-модуль Wokwi, AO | ADC1 PA0, FR-02/03/07 | BH1750 змінює величину й забирає ADC-досвід; потенціометр не є світловим входом |
| MPU6050 | I²C1 PB8/PB9, FR-02/04/07/11 | Контакт нахилу не дає числового вектора |
| Кнопка | GPIO PA1, FR-06 | Автозапис не замінює вибір точки оператором |
| LED PA5, USART2 | FR-01/08/10/13/14 | Дисплей не потрібний для CSV-аналізу |

Для FR-12 обрано внутрішню flash, останні 4 КіБ резервуються лінкером. Драйвер запису, дві сторінки, CRC, commit marker, reset і обрив запису перевірятимуться в ЛР3. Це не додає проводів. Якщо flash-модель не відтворить сценарій, зовнішня SPI NOR вимагатиме розширення схеми компонентом і CS/SCK/MISO/MOSI та окремого захвату SPI. UART-файл на хості не виконує FR-12.
