# Записи ЛР3 LightBench

Усі VCD стиснуто gzip без зміни вмісту; SHA-256 розпакованих записів наведені в evidence-manifest-final.json. Прошивка для S1/S2/S3 мала build ID `7eb6fca-401a17de6b40`, ELF SHA-256 `620f86877273314e973cd62c8575900f2111ecf7f448ad6ff84e71202403a58d`. Вихідний ELF та інші оригінали збережено локально за межами Git. Manifest містить контрольні суми локальних оригіналів, не всі з яких перенесені сюди.

S2 охоплює годину у VCD; UART має два сегменти з невідомим точним проміжком. У S3 використано генератор входу 1 Гц, а не ручні натискання; в аналізі VCD одна помилка стоп-біта. Перевірено CRC 74 завершених UART-знімків. Flash у моделі повернула помилку, тому збереження після reset не підтверджено. Фізичну плату, SDA LOW та відключення живлення не перевірено.
