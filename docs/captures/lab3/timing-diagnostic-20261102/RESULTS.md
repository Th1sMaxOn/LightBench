# Додаткове дослідження часу задач на TIM3

Діагностичний ELF `572e8e9f6e27e2b79caa194e5d79cc7c1a581fccccaeb6aad602c82c7c8310a8`, вихідні файли, preflight, S1/S3, команди, raw UART і VCD зберігаються у цьому каталозі. Він відрізняється від базового `ccacdff4…` лише вимірювальним кодом і змінює час виконання. Годинний S2 і результати S3 базового ELF йому не приписуються.

У 16-бітний TIM3 на 1 МГц накопичуються різниці між частими читаннями без переривання переповнення. Лічильник `clock_gaps` виявляє інтервали ≥60 мс між вимірювальними викликами за HAL tick; у зазначених запусках він нульовий. Проте HAL tick може пропустити час при stall: це не універсальний доказ коректності на фізичній платі. У S1 VCD дає 3300 ADC/IMU, максимальний інтервал ADC 26,5239 мс проти внутрішнього 26,509 мс; вікна майже, але не точно однакові. Для інших обгорток окремого GPIO-тесту немає.

|---|---:|---:|---:|---:|
| S1 | 66,018691 с | 8,229466 с / 12,47% | 45/57/6662 | 0 |
| Короткий номінальний preflight, не годинний S2 | 20,070507 с | 2,535614 с / 12,63% | 45/59/6643 | 0 |
| S3 | 45,106671 с | 29,981259 с / 66,47% | 45/208/15093 | 0 |

Порожні перевірки готовності не додаються у busy. Сума охоплює ADC, IMU, retry, прийняті байти, зміни кнопки, status, export і крок flash; вона включає активне очікування, обробку переривань усередині обгорток та вартість вимірювання. TX service та ISR поза обгортками не охоплені; метрика loop не включає TX service на початку наступного проходу та не є повним періодом циклу. Тому відсотки — **частка часу вибраних інструментованих інтервалів**, не повна достовірна CPU load і не нижня математична межа CPU. Роздільна здатність TIM3 1 мкс не дорівнює відомій повній похибці. Для початкового ELF окремого достовірного CPU load досі немає.

S3 діагностичної збірки: 80 BUTTON і POINT, 305 експортів з коректним CRC, реакція 29,257–41,717 мс за VCD, 72 POINT у вікнах передачі. Цей запуск не повторив помилку IMU, що була у базовому S3: це ще одна причина не змішувати виміряні версії. Деталі S1, S3, UART і хеш VCD — `suite/analysis.json`; raw й вихідні інструментів збережено. Повторний годинний S2 не запускався.
